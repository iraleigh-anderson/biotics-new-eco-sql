Processes for integrating BEC13 into the BC Conservation Data Centre Biotics database 

Element_Record_SQL_Insert_Automation_20251121.R
An R script to write SQL to insert blank element occurrence records for each new BEC13 Plant Association

BGC_Comparison.R
An R script to compare Biotics BGC records against authoritative BGC values and to manage the domain table

BGCD_Updates.R
An R script to update the Biotics BGC domain table with new BEC13 BGCs
